# 未来日记 📔

> 手机随时记录，电脑回看统计，长期沉淀让 AI 更懂你。

## 这是什么

不是传统"每天一篇"的日记 App，而是一个**个人生活数据库**：

- **手机（Android App）**：低摩擦快速记录 —— 一条记录可以只是一次心情打卡、一张照片配一句话、一次习惯打卡，不强迫写长文
- **电脑（网页端）**：时间线回看、全文搜索、情绪曲线/习惯热力图/健康图表统计
- **AI 记忆档案**：随时一键生成结构化的"个人记忆档案"（Markdown），粘贴给 ChatGPT / Claude / GLM 等任何 AI，它就能基于你真实的生活数据了解你
- **数据 100% 属于自己**：自建后端，服务器上就是 SQLite 文件 + 图片目录，拷走即备份

## 目录结构

```
├── server/    后端：Node.js (Fastify + SQLite)，REST API + 同步 + 档案导出 + AI 接口预留
├── web/       电脑网页端：React + Vite + ECharts
├── android/   手机 App：Kotlin + Jetpack Compose + Room（离线优先 + 后台同步）
└── docs/      设计文档（数据模型 / API / 同步协议）
```

## 快速开始

### 场景：拿到新电脑上部署 + 手机安装（最短路径）

1. 把整个项目文件夹拷过去（U盘/网盘均可），**双击根目录的 `未来日记.exe`**
   —— 无需安装任何东西，自动打开浏览器到 http://localhost:8787，首次让你设置密码
2. 把根目录的 `MiraiNikki.apk` 发到手机（微信文件传输助手/QQ/数据线），点击安装（允许"未知来源"）
3. 手机连上和电脑**同一个 WiFi**，App「设置」页填：
   - 服务器地址：`http://电脑局域网IP:8787`（**exe 窗口里会直接列出来，照抄即可**）
   - 密码：第 1 步设置的密码
   - 点「连接」→「立即同步」，之后每 15 分钟自动同步
4. 提示：首次启动时 Windows 防火墙若弹窗询问，选择"允许"

> 手机没连服务器也能正常记录（数据先存在手机本地），连上后会自动补同步。

> 说明：`未来日记.exe` 是打包好的独立服务端（自带运行环境，约 90MB），面向日常使用。
> 下面的开发方式（Node.js 源码运行）只在改代码时需要。
>
> 重新打包 exe（改完服务端代码后）：`cd server && npm run build:exe`，产物在 `dist-exe/`。

### 日常开发

#### 1. 启动后端（电脑上）

```bash
cd server
npm install
npm start          # 默认 http://0.0.0.0:8787
```

首次启动后，用网页或 App 设置密码即可。后端同时托管网页端（需先构建）：

```bash
cd web
npm install
npm run build      # 产物在 web/dist，后端自动托管
```

然后电脑浏览器打开 `http://127.0.0.1:8787` 就是完整网页端。

#### 2. 安装手机 App（Android）

```bash
cd android
# 用 Android Studio 打开直接运行，或命令行构建：
gradle :app:assembleDebug
# APK 在 app/build/outputs/apk/debug/app-debug.apk
```

App 内「设置」页填入服务器地址（手机与电脑同一网络时填 `http://<电脑局域网IP>:8787`）和密码，即自动开始同步（每 15 分钟 + 手动同步）。

#### 3. 部署到自己的服务器/NAS（可选）

```bash
cd server
docker compose up -d   # 数据卷：./data（数据库） ./uploads（图片）
```

公网使用建议前面挂一层 HTTPS 反代（Caddy/Nginx）。

## 记录的五种类型

| 类型 | 内容 | 示例 |
|------|------|------|
| 💭 心情 | 1-5 分 + 情绪词 + 一句话 | 😄 开心、平静 |
| 📝 文字 | 标题 + 正文 + 标签 | 日记、随想 |
| 📷 照片 | 多图 + 一句话说明 | 生活瞬间 |
| 🌙 梦境 | 梦境描述 + 醒来情绪 | 记下昨晚的梦 |
| ✅ 习惯 | 自定义习惯一键打卡 | 阅读、跑步、早睡 |
| 💪 健康 | 睡眠 / 体重 / 步数 | 手动记录 |

## 分享与导出（手机 App）

- **首页顶部就是「想记就记」输入框**：不用选类型，一句话点「记」即存——正文里写 `#标签` 会自动识别，零流程负担
- 想结构化时再用快捷入口：心情 / 梦境 / 照片 / 健康（文字弹层也只留一个正文框，标题可省）
- 习惯打卡不在首页占位，想用时进底部「习惯」页一键打卡

- 首页可用 **‹ › 翻看任意一天**，点右上角 **↗ 分享** 导出整天的日记；每条记录卡片上也有单独的"分享"按钮
- 三种方式：**一键复制文本**（直接粘贴到微信）、**分享文本**（调起系统分享面板）、**导出/分享 .md 文件**（Markdown 文件可发给对方或存档）
- 照片记录额外支持 **🖼 分享照片原图**：自动从服务器下载原图后以多图形式分享（需已连接服务器）
- 分享内容自动排版：日期星期、各类型记录的摘要、标签，末尾带"来自「未来日记」"落款

## AI 能力路线

- **现在**：档案导出（不依赖 AI 服务）——生成个人画像 + 统计 + 时间线要点的 Markdown
- **二期**：配置 `AI_BASE_URL / AI_API_KEY / AI_MODEL`（OpenAI 兼容，支持 GLM / DeepSeek / Ollama 本地模型）后启用内置 AI：自动摘要、打标签、情绪分析、对话式查日记（"我最近心情怎么样？"）
- AI 接口已预留（`/api/ai/*`），填环境变量即开

## 导入旧日记

把别处记的日记一次性搬进来（手机「设置」页 → 📥 导入旧日记；电脑网页端 → 「AI 档案」页 → 📥 导入旧日记）：

- **文本格式**（.md / .txt / 直接粘贴）：按"日期行"自动分天，每天存为一条文字记录。支持的日期行写法：
  ```
  # 2026-01-15
  ## 2026年1月15日
  2026/1/15
  [2026-01-15]（一些 App 导出的格式）
  2026-01-15（ISO 纯日期行）
  ```
  正文里的 `#标签` 照常自动提取；无法归入日期的内容会提示（可一键归到今天）。
- **JSON 格式**：本应用「全量备份」导出的 json 可直接导入（换机/重建时整库迁移）。
- 手机端导入到本地数据库，联网后随自动同步上传；电脑端直接入服务库。
- 导入是"新增"不是"覆盖"，重复导入同一文件会产生重复记录（低频一次性操作，建议导一次确认无误）。

## 数据安全与备份（重要）

日记数据有三层保护，更新 App **不会**丢数据：

1. **App 升级安全**：数据库升级走显式迁移（代码里禁止了"删库重建"式升级），直接覆盖安装 APK 数据保留。
2. **手机本地备份（强烈建议每周一次）**：手机「设置」→「💾 备份与恢复」→「📤 导出备份」，生成全量 json 文件（所有记录+习惯+标签）。存到下载目录、微信文件传输助手、网盘均可。恢复时用「📥 导入」选这个 json 即可完整还原（重复恢复自动跳过已有数据，安全）。
3. **服务器副本**：连上自建后端后，手机数据每 15 分钟同步一份到服务器；网页端「AI 档案」页也有全量备份下载。服务器备份 = 拷走 `server/data` + `server/uploads` 两个目录。

> 换新手机：新手机装 APK → 设置页「导入」选备份 json → 完整恢复。

## 安全说明

- 单用户 Token 认证，密码哈希存储
- 图片按 UUID 直读（不可枚举）
- 局域网明文 HTTP 可用；公网请务必上 HTTPS
