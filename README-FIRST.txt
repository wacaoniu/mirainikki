  未来日记 MiraiNikki —— 新手第一课（电脑端 + 连手机）
  全部做完约 3 分钟，电脑上不需要安装任何东西
════════════════════════════════════════════════════════════

这个 App 分两块：
  · 手机（MiraiNikki.apk）—— 用来记录，数据先存在手机里
  · 电脑（就是本文件夹）—— 用来回看、统计、生成 AI 档案

手机和电脑连上之后会自动同步：手机记的东西，电脑上就能看到。


【第 1 步】启动电脑端（每次用都要做）
────────────────────────────────────
双击本文件夹里的    未来日记.exe

· 会弹出一个小黑窗口，同时自动打开浏览器（没有就手动访问
  http://localhost:8787 ）
· 第一次会让你设置一个密码，随便设一个好记的（6 位数字就行），
  记牢 —— 手机连接时要用同一个密码
· 小黑窗口要一直开着（最小化就行），关掉就等于停止服务
· 如果 Windows 提示"是否允许访问网络"，点"允许"


【第 2 步】把 App 装到手机上
────────────────────────────────────
把 MiraiNikki.apk 发到手机（微信文件传输助手 / QQ / 数据线都行），
点击安装。手机可能提示"未知来源"，允许一下即可。


【第 3 步】手机连电脑（关键的一步）
────────────────────────────────────
1. 先确认手机和电脑连的是【同一个 WiFi】
2. 打开手机上的 未来日记 App → 底部「设置」页
3. 看电脑上那个黑窗口，里面会列出几行这样的地址：
       http://192.168.x.x:8787
   （可能有两三行，一般选 192.168 开头的那行；
     如果只有一个，就用那个）
4. 把这行地址填到 App 的「服务器地址」框里，
   再填第 1 步设置的密码
5. 点「连接」→ 出现"✓ 连接成功"就成了
6. 再点一下「立即同步」，手机里之前记的内容会全部传到电脑

之后每 15 分钟会自动同步一次，不用管它。
平时只记录不连接也没问题，数据都好好地存在手机里。


【第 4 步】在电脑上看你的日记
────────────────────────────────────
浏览器打开 http://localhost:8787 ，你就能：
  · 时间线：翻看每一天的记录
  · 统计：心情曲线、习惯打卡、健康数据图表
  · AI 档案：一键生成"个人记忆档案"，粘给 ChatGPT/Claude 就能让 AI 了解你


════════════════════════════════════════════════════════════
  常见问题
════════════════════════════════════════════════════════════

Q: 手机点"连接"一直失败？
A: 按顺序检查：
   1. 手机和电脑是不是连的同一个 WiFi？
      （手机用的流量、或连了别家的 WiFi 都不行）
   2. 黑窗口是不是开着？关了就重新双击 启动.bat
   3. 第一次启动时 Windows 防火墙弹过窗吗？如果弹过"允许"即可；
      如果当时点了"取消"，去 控制面板 → Windows 防火墙 → 允许应用
      通过防火墙 里把 未来日记 勾上"专用网络"
   4. 地址是不是填对了？注意是 http:// 开头、:8787 结尾

Q: 换新电脑怎么办？
A: 把本文件夹整个拷过去，双击 未来日记.exe 即可。
   数据在 server 文件夹的 data 和 uploads 两个目录里，
   想迁移数据就把这两个目录一起拷过去。

Q: 电脑上双击 exe 被杀毒软件拦了？
A: 偶尔有杀软对这种"自带运行环境"的程序比较敏感，选择"允许/信任"即可；
   实在不行，用 server 目录里的 启动.bat 代替（那种方式需要电脑装了 Node.js）。

Q: 手机会丢数据吗？
A: 手机 App 里「设置」→「导出备份」可以把全部记录存成一个 json 文件
   （存微信/网盘都行）。换手机、误删都能用它恢复。建议每周导一次。

Q: 关掉电脑上的黑窗口，手机还能记吗？
A: 能。记录优先存在手机本地，电脑不在也能记，连上后自动补同步。
